# Installer images

The Windows installer (NSIS) shows `sidebar.bmp` on its first and last pages, and `header.bmp` at the top of the others. They are drawn at twice the size the installer shows them at on Windows 11 at 100% scaling (191 × 338 and 170 × 62 px, measured), in that same shape so they aren't squashed; the installer scales them to fit. Both are 24-bit BMP files.

They are drawn by `images.html` in the Sastra™ palette. To change them, edit that page, open it in a browser, screenshot the two blocks at 200% zoom, and save each as a 24-bit BMP here.
